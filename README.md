# Анкета участника курса программирования

Домашнее задание №1 «Анкета», занятие 03. .NET MAUI, XAML и C#.
Русскоязычная анкета для Windows и Android. Все данные остаются в памяти:
сохранение, регистрация аккаунта и отправка писем не реализованы и не требуются заданием.

## Запуск на Windows
1. Установите Visual Studio с поддержкой .NET 10 и компонентом разработки .NET MAUI.
   Нужны .NET 10 SDK, MAUI workload и Windows SDK. Интернет нужен для установки и NuGet restore.
2. Распакуйте архив целиком. Откройте `AnketaMaui.sln`.
3. Дождитесь восстановления пакетов. Выберите проект AnketaMaui и цель **Windows Machine**.
4. Нажмите F5. Для Android выберите настроенный эмулятор или подключённый телефон.

Альтернатива в терминале на Windows с установленными инструментами:
```powershell
dotnet workload restore AnketaMaui.csproj
dotnet build AnketaMaui.csproj -f net10.0-windows10.0.19041.0
dotnet build AnketaMaui.csproj -f net10.0-windows10.0.19041.0 -t:Run
```
Не открывайте проект в редакторе как HTML-сайт: это нативное MAUI-приложение.
Если в учебной аудитории используется .NET 8 или 9, проект нужно согласованно
адаптировать под эту версию; простой замены цифры недостаточно (в .NET 10 DatePicker.Date nullable).

## Как работает
- Имя: минимум 2 символа после удаления пробелов по краям.
- Почта: проверка формата через MailAddress.TryCreate; существование ящика не проверяется.
- Курс: обязательный выбор из трёх вариантов.
- Дополнительно выбираются уровень, интересы, дата, часы и напоминания, вводится цель.
- «Показать результат» проверяет поля, сообщает ошибки и показывает все ответы.
- При изменении ответа старый результат скрывается, чтобы не показывать устаревшие данные.
- «Очистить» возвращает начальное состояние, включая дату 01.11.2026 и 5 часов.

## Структура
- MainPage.xaml — разметка и явно заданные свойства контролов.
- MainPage.xaml.cs — проверка, результат, сброс, обработчики событий.
- App.xaml — общие стили; App.xaml.cs — создание окна.
- MauiProgram.cs — точка настройки приложения.
- Resources — локальная иллюстрация, иконка и заставка.
- Platforms — точки входа Windows и Android.
- REQUIREMENTS.md — соответствие заданию; MANUAL_TESTS.md — проверка перед сдачей.
- START_AR.md — инструкции на арабском; EXPLANATION_RU.md — объяснение кода.

Создайте репозиторий GitHub и загрузите содержимое папки проекта (без bin, obj, .vs).
В Settings → Collaborators → Add people найдите Rews и убедитесь, что это Andrei Goncharov.
Добавьте преподавателя, затем заполните учебную анкету по ссылке из сообщения преподавателя.
Сам URL анкеты в исходных данных отсутствует. Создание репозитория, приглашение и отправка
анкеты этим архивом не выполняются.
